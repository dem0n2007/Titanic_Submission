一、导入模块说明
1. Dataset, DataLoader：PyTorch 数据集相关工具。Dataset 用于自定义数据集类封装特征与标签；DataLoader 实现批次加载、数据打乱，满足 PyTorch 数据加载机制的要求。
2. train_test_split：划分数据集，将原始数据集切分为训练子集与测试子集，支持分层采样，保证正负样本比例稳定。
3. StandardScaler：标准化转换器，对数值特征做标准化处理，消除不同量纲带来的影响。

train_raw, test_raw = train_test_split(

    random_state=42,      # 固定随机种子，每次运行划分结果不变，实验可复现
    stratify=df_all["Survived"]   # 分层采样！保持训练、测试集生还/死亡比例和原数据集一致
)

三、防止数据泄露
age_mean_train：只拿训练集计算年龄均值，后面填充训练集、测试集缺失年龄都用这个均值
embarked_mode_train：只拿训练集计算登船港口众数（出现最多的值），填充缺失港口用这个值
错误做法：用全部数据集算均值 / 众数，会把测试集信息带入训练，造成数据泄露

四、将标签转化成pytorch能阅读的数据张量
X_train_tensor = torch.tensor(X_train, dtype=torch.float32)
y_train_tensor = torch.tensor(y_train, dtype=torch.float32).unsqueeze(1)
运用tensor()函数将numpy数组转化成张量 
y需要用.unsqueeze(1)再补全一个维度，是因为y只有一列，是一维的，而进入神经网络的时候我们需要用一个二维的量，因此要为y加上一列

五、自定义dataset
1. __init__：构造函数，保存特征张量 X、标签张量 y
2. __len__：返回数据集总样本数量，DataLoader 需要知道一共有多少样本
3. __getitem__(idx)：按下标 idx 取出单条样本：返回(特征，标签)

六、自主二分类模型
class TitanicModel(torch.nn.Module):新建一个神经网络类，继承 PyTorch 自带的模型基类nn.Module。继承之后，这个类自动获得：参数管理、GPU 迁移、保存模型等能力。
def __init__(self, input_dim):构造函数，创建模型实例的时候执行一次。
input_dim：输入特征的数量
